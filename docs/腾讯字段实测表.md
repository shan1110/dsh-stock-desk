## 2. 三个必须先挡住的陷阱

1. **`[47]`/`[48]` 在指数上返回 `-1`。** 直接显示会得到「涨停价 -1」。
2. **`[38]` 换手率、`[39]` 市盈率、`[46]` 市净率在指数上返回看似合理的假值**（0.69 / 16.24 / 0.00）。它们不是空、不是 -1，**照搬就会显示成「上证指数 市盈率 16.24」**。
3. **`[36]` 成交量在指数上是 333809521，不是「手」。** 单位语义随品种变。

结论：**必须按品种白名单决定字段是否输出**，判断依据用 `[61]` 品种标记（比靠代码前缀猜品种可靠）。

## 4. 炸板 / 涨停的判定（用本表字段，不用「涨幅≥9.9%」）

```
涨停 = [3] >= [47]
炸板 = [33] >= [47] and [3] < [47]
跌停 = [3] <= [48]
```

**不能用「涨幅 ≥ 9.9%」**：ST 是 5cm、创业板/科创板是 20cm、北交所是 30cm，涨幅阈值一刀切会同时漏报和误报。
`[47]` 涨停价是接口直接给的，自带正确的涨跌幅上限。

指数不能参与该判定（`[47]` = -1）。
