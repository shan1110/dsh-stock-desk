# README 截图清单

README「功能」一节引用的图都放在本目录。改界面后按本文件重拍，文件名保持不变，README 不用动。

## 拍摄约定

- 浏览器视口 **1680 × 1200**，缩放 100%，**深色主题**
- 设备像素比按 2 抓，导出前降到 **1400 px 宽**（详情图 1362 px），单张控制在 250 KB 以内
- 只截行情台区域，**不要**带 DSH 侧边栏、浏览器地址栏与书签栏
- 持仓与价格提醒一律用**示例值**（成本 9.20 / 500 股、0.88 / 2000 份，提醒 8–10 / 0.80–1.00），
  不公开真实仓位。改的是宿主配置，必须走 `POST /api/stock-desk/config` 再还原：
  直接改 `~/.dsh/stock-desk/config.json` 不会生效，宿主内存里有一份缓存
- 截图里的行情是 2026-10-20 早盘的真实数据

## 清单

| 文件 | 拍什么 | 对应 README 小节 |
|---|---|---|
| `overview.png` | 行情台整页：标题行 + 指数 + 涨跌家数 + 涨停格子 + 自选表 + 数据源行 | 盘面总览 |

| `watchlist-edit.png` | 自选卡编辑态：点**某一行的行尾**「编辑」，只有那一行变成输入框 | 自选、持仓与监控 |

## 待补：板块

`overview.png` 里**没有板块卡**，`sectors.png`（板块格子）与 `drill.png`（板块下钻）也尚未拍。

原因是 2026-10-20 上午同花顺行业榜不可用：`http://q.10jqka.com.cn/thshy/` 对普通请求返回
200 但每行「板块 / 涨跌幅 / 领涨股」全是空值与 `0.00`，带 `v` cookie 的真实浏览器访问同一
路径回 403，因此板块卡显示「板块：拿不到」。整页总览拍摄时用 CSS 把这张空卡隐藏了，
不公开一张不可用的区域。

上游恢复后要做三件事：

1. 重拍 `overview.png`（不要再隐藏板块卡）

3. 补拍 `drill.png`：点一个板块格子下钻，再点其中一只股票，让右栏出现 K 线 ——
   一张图同时说明「下钻 + 详情 + 分页」
4. 在 README「板块」小节补上这两张图

## 重拍步骤

1. 确认插件已激活且客户端半边已进启动图：

   ```powershell
   (Invoke-RestMethod http://127.0.0.1:8820/api/stock-desk/diag).data.wired
   ```

2. 打开 `http://127.0.0.1:8820`，点侧边栏「行情台」，等卡片右上角的快照时间开始跳动
3. 按上表逐块截图（元素级截图，不要整屏截图再裁）
4. 降采样到 1400 px 宽并压缩，覆盖本目录同名文件
5. 有新增或删除图时，同步改本清单与 README
