# README 截图清单

README 的「界面」一节引用下列 5 张图。文件缺失时 GitHub 会显示破图，
补齐后自动生效，无需改动 README。

## 拍摄约定

- 浏览器窗口宽度建议 **1440 px 以上**，缩放 100%
- 用**深色主题**拍（README 也按深色排），若要浅色，5 张统一
- 只截行情台区域，**不要**带上浏览器地址栏和书签栏
- 格式 PNG，单张控制在 400 KB 以内
- 涉及真实持仓时，可以先把份额改成示例值，避免公开自己的仓位

## 清单

| 文件名 | 拍什么 | 拍摄步骤 |
|---|---|---|
| `overview.png` | 整页总览 | 打开行情台，滚动到顶部，包含「指数 + 涨跌家数 + 成交额」那一行与下面的涨停卡 |
| `sectors.png` | 板块格子 | 只截板块那一块：涨最狠 10 个 / 跌最狠 10 个的格子 |
| `drill.png` | 板块下钻 + 右侧详情 | 点一个板块格子进入下钻，再点其中一只股票，让右侧出现 K 线 —— 这张最重要，一张图说明「下钻 + 详情 + 分页」三个功能 |
| `watchlist.png` | 自选与持仓 | 点右上角「编辑」进入编辑态，让成本价、份额、今日盈亏、持仓盈亏、价格提醒这几个输入框都露出来 |
| `pill.png` | 对话页药丸 | 回到对话页，截右下角那个药丸，保留一点周围页面作背景 |

## 备选（有则更好）

| 文件名 | 拍什么 |
|---|---|
| `settings.png` | 设置页：涨跌配色、行高、药丸指数 |
| `kline.png` | 日 K 线视图（`drill.png` 里如果是分时，这张补上 K 线） |

```powershell
cd E:\dsh-plugin

git commit -m "docs: 补充 README 界面截图"

```
